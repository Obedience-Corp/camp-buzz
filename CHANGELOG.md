# Changelog

All notable changes are documented here. This project follows Semantic
Versioning after its first stable release.

## Unreleased

### Added

- Independent `camp-buzz` plugin commands for binding, diagnostics, posting,
  configuration display, and Festival hook scaffolding.

- Bounded subprocess input and execution, validated relay/channel/gate inputs,
  atomic restrictive configuration writes, symlink rejection, and secret scans
  across the working tree and full Git history.

# Security policy

## Supported versions

Security fixes are provided for the latest published release. Before the first
stable release, fixes are applied to `main`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue or include secrets, private keys, relay credentials, or private
Buzz data in a report.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Obedience Corp will acknowledge a report as capacity permits and
coordinate disclosure after a fix is available. This project provides no paid
support or guaranteed response-time agreement.

For vulnerabilities in Buzz itself, report them to the Block Buzz project. For
vulnerabilities in Camp or Festival, report them to the corresponding
Obedience Corp repository.

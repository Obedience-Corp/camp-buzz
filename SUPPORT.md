# Support

camp-buzz is a community-supported integration plugin.

- Use GitHub Discussions for usage questions when available.
- Open a bug report for reproducible camp-buzz defects.
- Send vulnerabilities through private reporting as described in
  [SECURITY.md](./SECURITY.md).

Support covers this plugin's configuration, process invocation, and Festival
footer behavior. It does not cover operating Buzz, relay availability, account
membership, or Block's hosted services. Compatibility is verified against a
disposable local relay; hosted or production relay support is not claimed.
